    Each model trades live only when switched ON here (and live trading is on in Railway). Pick the rule set and exit per model. Option 1 = BTC filter on shorts, skip late entries, breakeven at +2R (under-floor without breakeven; daily failure-swing short without the late-entry skip).     Signal list

    waiting = setup seen, entry trigger not yet; enter = enters at the next open; open = the trade it describes is running; closed = finished in the last 14 days. LIVE = the row a model switched on trades. MACD gap = daily MACD vs its signal line, 12/26/9, as a share of the MACD line; + = the gap points the trade's way. Pre-cross = the gap points against the trade but is closing (the lines converging, not crossed yet). MACD divergence = price made a new low (high) while the MACD line did not, over the last two daily pivots. Display only: no rule uses these.
